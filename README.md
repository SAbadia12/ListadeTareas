# Mi semana — Lista de tareas

Aplicación web sencilla para organizar pendientes. Permite agregar tareas con una fecha límite opcional y marcarlas como completadas. No incluye funciones para editar o eliminar tareas.

## Cómo usar

Abre `index.html` en un navegador. Escribe una tarea, agrega una fecha si la necesitas y pulsa **Agregar tarea**. Marca la casilla de una tarea para indicar que ya la completaste.

## Archivos

- `index.html`: estructura de la aplicación.
- `css/styles.css`: estilos y diseño adaptable a celular y escritorio.
- `js/script.js`: creación de tareas, marcado de completado y actualización del progreso.
- `img/img.png`: imagen incluida en el panel de inspiración.

Las tareas se mantienen mientras la página está abierta; al recargar el navegador, la lista vuelve a iniciar vacía.
