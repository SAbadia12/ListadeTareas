# Mi semana — Lista de tareas

Aplicación web sencilla para organizar pendientes. Permite agregar, editar y eliminar tareas con fecha límite opcional, desglosarlas en pasos y marcar las tareas y sus pasos como completados.

## Cómo usar

Abre `index.html` en un navegador. Escribe una tarea, agrega una fecha si la necesitas y, opcionalmente, escribe sus pasos en el campo **Pasos**, uno por línea. Pulsa **Agregar tarea**. Usa **Editar** para cambiar el nombre, la fecha o los pasos de una tarea, o **Eliminar** y confirma para quitarla de la lista. Puedes marcar cada paso por separado; cuando todos estén completados, la tarea principal también se marcará como completada. Al marcar la tarea principal, todos sus pasos se marcarán a la vez.

## Archivos

- `index.html`: estructura de la aplicación.
- `css/styles.css`: estilos y diseño adaptable a celular y escritorio.
- `js/script.js`: creación, edición y eliminación de tareas y pasos, marcado de completado y actualización del progreso.
- `img/img.png`: imagen incluida en el panel de inspiración.

Las tareas se mantienen mientras la página está abierta; al recargar el navegador, la lista vuelve a iniciar vacía.
